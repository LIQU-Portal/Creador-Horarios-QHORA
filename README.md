# Creador de Horarios para LQUI

Aplicación independiente para consultar la oferta académica 2026B de CUCEI y generar propuestas de horario a partir de claves de materias.

- Las materias sin oferta se conservan como pendientes.
- La restricción de cupo puede activarse o desactivarse.
- La prevención de traslapes puede activarse o desactivarse.
- Las combinaciones se priorizan por disponibilidad.
